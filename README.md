# Muhammad Farid Husain — Portfolio

Single-page Fullstack Developer portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

Portfolio content is stored in `src/data`, page sections in `src/sections`, and shared interface components in `src/components`.
