## 8. Cara Kerja Pengembangan Software

Portfolio menggambarkan workflow pengembangan berikut:

1. **Understand** — memahami problem, kebutuhan pengguna, dan feature requirements.
2. **Plan** — merencanakan application flow, teknologi, data model, API, dan component structure.
3. **Structure** — menentukan architecture, application state, repository boundaries, dependencies, serta pemisahan presentation/domain/data.
4. **Build** — membangun UI, business logic, state management, API integration, authentication, dan database interaction.
5. **Test & Debug** — menguji behavior, API response, UI state, error handling, edge cases, dan integration issues.
6. **Improve** — memperbaiki code structure, duplication, UI/UX, performance, readability, dan maintainability.

### Jawaban singkat untuk interview: “Bagaimana cara kamu mengerjakan fitur?”

Saya mulai dengan memahami masalah dan kebutuhan pengguna, lalu merancang application flow, data model, dan struktur komponen. Setelah itu saya menentukan pembagian state, repository, dependency, serta data source sebelum membangun UI dan business logic. Saya menguji behavior, error state, API response, dan edge cases, kemudian melakukan refactor untuk meningkatkan readability, maintainability, performance, dan UX.
